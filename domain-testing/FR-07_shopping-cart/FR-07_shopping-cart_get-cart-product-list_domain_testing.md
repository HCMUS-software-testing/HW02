README yêu cầu giỏ trống có hình minh họa và thông báo rõ ràng, nhưng API không kiểm chứng được hình minh họa. Các kết quả Web mô tả hành vi quan sát được trên giao diện; các kết quả API ghi status code và body response thực tế.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |

## 5. Ghi chú rủi ro

- API specification của `GET /api/cart` chưa mô tả body phản hồi, status code lỗi, hoặc tên field cụ thể; khi thực thi cần ghi lại body thực tế và đối chiếu với yêu cầu Web/README.
- Kết quả quan sát qua Web UI và Postman cần tách riêng: mở màn hình Giỏ hàng sau khi thêm bằng UI không yêu cầu tester gửi bearer token, còn `GET /api/cart` trong Postman cần `Authorization: Bearer <valid_user_token>`. Nếu muốn `GET /api/cart` đọc được item vừa thêm trong Postman, phải dựng dữ liệu bằng `POST /api/cart` có bearer token trước đó.
- Chức năng được yêu cầu là `Hiển thị danh sách sản phẩm (Lấy giỏ hàng)`, nên artifact này không thay thế Domain Testing riêng cho `FR-05: Product listing and search`.
- Một số kỳ vọng như hình minh họa giỏ trống, nhãn `Tổng cộng`, nút `+/-`, và cột `Thao tác` chỉ kiểm chứng được qua Web, không kiểm chứng trực tiếp qua `GET /api/cart`.
- Tài liệu không nêu giới hạn tối đa cho số lượng item, số lượng mỗi item, đơn giá hoặc tổng tiền; BVA chỉ dùng các biên được đặc tả hoặc biên tự nhiên của trạng thái rỗng/có dữ liệu.
- Tài liệu không cung cấp sẵn giá sản phẩm trong kho; khi thực thi testcase có tính tiền, tester phải lấy đơn giá thực tế hiển thị trên UI làm `X`/`Y` rồi đối chiếu công thức, không dùng giá cố định do artifact tự đặt ra.
- Các testcase cần có sản phẩm trong giỏ phải dựng dữ liệu tiền điều kiện qua UI thay vì gọi trực tiếp `POST /api/cart`, vì artifact này không có đủ context về kho hàng/tồn kho và tính hợp lệ của product id khi thêm bằng API.
