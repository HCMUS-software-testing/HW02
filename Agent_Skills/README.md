# Hướng dẫn nộp Agent Skills & Demo Video (Bonus 10 điểm)

Chúc mừng, bạn đã tạo thành công 2 Agent Skills quan trọng là:
- `Domain_Testing_Prompt.md`
- `BVA_Prompt.md`

## Yêu cầu từ Giảng viên:
> "Submit the skills together with demonstration videos (YouTube links) that show, end to end, how you used the skills on a complete feature."

## Cách lấy điểm phần này:
1. Bạn mở ứng dụng quay màn hình (OBS, Windows Game Bar, Bandicam...).
2. Bật trình duyệt, chia nửa màn hình: Một bên là file `Agent_Skills` của bạn, một bên là giao diện chat với AI (ChatGPT, Gemini...).
3. Bắt đầu quay:
   - Bạn demo tính năng **FR-04 (Personal profile management)**.
   - Bạn copy **Step 1** trong `Domain_Testing_Prompt.md`, dán mô tả FR-04 vào và enter cho AI chạy.
   - Khi AI trả kết quả, bạn đọc, nhận xét (như 1 QA thật), có thể bảo AI "Mày thiếu biến X rồi, sửa lại bảng đi".
   - Tiếp tục copy **Step 2**, rồi **Step 3**.
   - Làm tương tự một chút cho `BVA_Prompt.md`.
4. Render video, đăng lên YouTube (để chế độ Unlisted/Không công khai).
5. **Dán link YouTube vào file này** để nộp:
